# XMind 源文件

本目录保存实习期间制作的游戏策划思维导图源文件，作为上级目录 Markdown 总结的补充材料。

## 文件目录

- `大地图view.xmind`：大地图不同层级的对象表现与交互规则
- `大地图优化.xmind`：大地图缩略层和总览层的优化记录
- `无尽冬日操作层view.xmind`：地图战略建筑的操作层状态
- `选兵出战界面VIEW.xmind`：编队、英雄、士兵、预设与出征交互
- `英雄卡牌详情页.xmind`：英雄详情页初版拆解
- `英雄卡牌详情页（修改版）.xmind`：英雄详情页迭代稿
- `英雄卡牌详情页（修改版）(1).xmind`：英雄详情页迭代稿
- `英雄卡牌详情页（修改版）（2）.xmind`：英雄详情页迭代稿
- `英雄系统.xmind`：英雄系统 View 层设计
- `英雄系统model层（修改版）.xmind`：英雄系统 Model 层设计

## 使用方式

GitHub 通常不会直接预览 `.xmind` 文件。请点击目标文件后选择下载，再使用 XMind 客户端打开。

## 说明

- 文件仅用于个人学习记录和游戏策划方法交流。
- 文件包含分析过程中使用的游戏界面截图。
- Markdown 总结已经做了脱敏和方法化整理，更适合直接在线阅读。
